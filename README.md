# BCA Entrance Preparation App

This project is based on the work given in the 1st semester of BCA.

We are developing a console-based application designed to help students prepare for BCA entrance exams.

## Features
- Contains around 200 important questions for each subject:
  - Mathematics
  - English
  - Computer General Knowledge
- User-friendly interface
- Practice-based learning approach

## Objective
The main goal of this application is to engage students in interactive practice and help improve their chances of scoring good marks in BCA entrance exams.

In most entrance exams (like BCA), 40–60% of questions are pattern-based or repeated concepts. Practicing these questions can significantly improve performance.
